
# Musubi

An evolutionary robotics and reinforcement learning sandbox built with PyBullet.

## Goals

- Learn PyBullet
- Build procedural creatures
- Implement evolutionary algorithms
- Train agents using Reinforcement Learning
- Experiment with emergent behaviour

## Tech Stack

- Python
- PyBullet
- NumPy
- Gymnasium
- Stable Baselines3
